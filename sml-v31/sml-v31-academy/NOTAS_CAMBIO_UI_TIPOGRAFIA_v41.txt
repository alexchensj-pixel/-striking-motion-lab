SML ACADEMY — V41 UI REFRESH

Objetivo
Unificar diseño gráfico, interfaz, tipografía y comportamiento responsive sin tocar el contenido de las lecciones ni los esquemas existentes.

Cambios
- Sistema tipográfico coherente: Big Shoulders Display para titulares, Inter Tight para lectura y JetBrains Mono para metadatos técnicos.
- Jerarquía más clara entre títulos, entradillas, etiquetas, cuerpo y microcopy.
- Ajustes de ritmo vertical, espaciado, anchuras de lectura y contraste.
- Tratamiento consistente de módulos, filas de lecciones, botones, progreso, temporizador, panel lateral y espacios de vídeo.
- Estados hover y focus-visible más claros; objetivo táctil mejorado en controles clave.
- Refinamiento responsive para escritorio, tablet y pantallas pequeñas.
- Se mantienen el contenido, el comportamiento y los esquemas técnicos existentes. No se han generado ni añadido ilustraciones nuevas.

Validación
Se ha comprobado la estructura del archivo ZIP y la presencia de los cambios CSS. No se ha podido ejecutar el build de Vite en este entorno porque las dependencias no estaban instaladas y npm install agotó el tiempo de espera. Por tanto, no se afirma que el build esté validado.
